1. 本仓库提供辰龙操作系统的构建方法。
2. 辰龙操作系统可以基于Linux内核，也可以基于StarryOS内核。包含完整的服务和应用程序，以满足智能汽车、机器人、物联网等领域的复杂系统的需求。
3. 本仓库需要为不同的SOC, 不同的内核，提供统一的构建方法。SOC有SG2002、RK3588、昇腾处理器等。内核有Linux内核、StarryOS内核。
4. 构建的流程是：构建内核 -> 构建用户空间 -> 构建镜像。
5. 对于有源代码的程序，从源代码开始构建。对于没有源代码的程序， 从二进制文件开始构建。
6. 使用Makefile定义构建规则。使用PLATFORM、KERNEL等变量来指定构建的平台和内核。
